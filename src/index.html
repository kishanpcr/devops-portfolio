Container infrastructure lab

Terraform-managed Docker services

An Nginx status page and PostgreSQL service defined together in Terraform, with workspace-specific names, ports, and a shared Docker network.

  • Terraform
  • Docker
  • Nginx
  • PostgreSQL
Explore tf-docker-lab ↗

What the code demonstrates

  • Container lifecycle and network configuration, plus a host-mounted PostgreSQL data directory.
  • HTTP and pg_isready health checks; a shell entrypoint waits for database readiness before generating the status page.
  • Pull-request workflows for Terraform format, validation, and plan; a main-branch workflow for apply.

Inspect: Resources & checks · Readiness script · Workflows

Lab boundary: example credentials and host-published database ports need review before reuse outside a local lab.

Cloud provisioning lab

AWS web infrastructure with Terraform

Configurable EC2 web instances bootstrapped with Apache, a security group, and an S3 bucket for static assets.

  • Terraform
  • AWS EC2
  • Amazon S3
  • Linux
Explore AWSWebserverTFScripts ↗

What the code demonstrates

  • AMI lookup, configurable instance count, environment tags, and shell-based web server bootstrap.
  • HTTP/HTTPS ingress rules and SSH restricted to the 10.0.0.0/8 range.
  • S3 versioning, AES256 server-side encryption, and all four public-access-block settings.

Inspect: EC2 & network rules · S3 controls

Lab boundary: allowing port 443 does not configure TLS. Certificates, load balancing, and monitoring are follow-up work.
